# Diagrams

Source for the seven UML diagrams in the PRD: `gantt.mmd`, `erd.mmd`, `use-case.mmd`, `class.mmd`, `sequence-round.mmd`, `sequence-auth.mmd`, and `sequence-lobby.mmd`. Edit the `.mmd` file, then run `npm install` and `npm run render` here to rebuild every PNG with the Teraphobia theme. The first run may need `npx playwright install chromium`.

Fonts in `fonts/` are Bricolage Grotesque and IBM Plex, both under the SIL Open Font License.
